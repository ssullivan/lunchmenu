lunchmenu

Announce your school's lunch menu around the house every weekday morning.

Reads LINQ Connect's public JSON API — the system many US school districts use to publish menus. No account, no API key.

Three channels

Spoken audio

Announces the day's menu out loud on a Google Home, Nest, or Chromecast speaker.

TV toast

Pops an on-screen toast with the menu on every paired LG webOS TV.

Menu screen

Wakes one TV from standby and shows the full menu page on its screen.

Each channel runs independently: a TV that's unplugged doesn't stop the audio, and a speaker that's wandered off the network doesn't stop either TV.

Also just a CLI

Print tomorrow's menu from the command line, or leave a small web page up on any screen in the house.

Try it

git clone https://github.com/ssullivan/lunchmenu.git
cd lunchmenu && just install
lunchmenu tomorrow
